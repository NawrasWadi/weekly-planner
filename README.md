## 📖 نظرة عامة

**خطتي الأسبوعية** تطبيق يساعدك على تخطيط أسبوعك والالتزام بخطتك. تضيف مهامك على أيام الأسبوع القادم، وتنقلها بين ثلاث مراحل واضحة: من التخطيط، إلى التنفيذ، إلى الإنجاز، مع شرائط تقدم وعبارات تحفيزية ورسائل تشجيع تبقيك ملتزماً.

الفكرة بسيطة: **علّم ✓ وتحرّك للأمام**.

## ✨ المميزات

### 🗂️ ثلاثة أقسام بنظام Kanban

| القسم | الوصف | عند تعليم ✓ |
|---|---|---|
| 📋 **المهام اليومية** | المهام المخططة ولم تبدأ بعد | تنتقل إلى «قيد التنفيذ» |
| ⚡ **قيد التنفيذ** | المهام التي تعمل عليها الآن | تنتقل إلى «المكتملة» |
| ✅ **المكتملة** | المهام المنجزة | عند إزالة العلامة تعود إلى «قيد التنفيذ» |

- انتقال تلقائي مع أنيميشن سلس.
- عدّاد لعدد المهام في كل قسم.
- حذف أي مهمة بضغطة واحدة.

### 📆 تخطيط لسبعة أيام

- شريط أيام يبدأ من **اليوم** ويعرض الأيام السبعة القادمة (اسم اليوم + التاريخ).
- اختيار يوم يعرض مهامه فقط في الأقسام الثلاثة.
- كل مهمة لها: **عنوان**، **وصف اختياري**، و**أولوية** (عالية، متوسطة، منخفضة) بلون مميز على حافة البطاقة.

### 🎯 الأهداف الأسبوعية

- إضافة أهداف الأسبوع، وتعديلها (✎)، وحذفها، وتعليمها كمنجزة.
- شريط تقدم خاص بالأهداف.

### 📊 شرائط التقدم

- **إنجاز اليوم:** نسبة المهام المكتملة في اليوم المختار.
- **إنجاز الأسبوع:** نسبة المكتمل من كل المهام.
- **أهداف الأسبوع:** عدد الأهداف المنجزة من الإجمالي.

### 💪 التحفيز

- شعار ثابت بارز في الهيدر.
- **21 عبارة تحفيزية** عن التخطيط والالتزام، تتغير يومياً أو بزر «عبارة جديدة».
- رسائل تشجيع (Toast) عند بدء مهمة أو إنجازها أو إنجاز كل مهام اليوم.
- احتفال بسيط (Confetti) عند الإنجاز.
- حالات فارغة (Empty States) محفّزة في كل قسم.

### 🌗 الوضع الداكن

- مفتاح تبديل في الهيدر.
- يتبع إعداد جهازك (`prefers-color-scheme`) في أول زيارة، ثم يحفظ اختيارك.
- ألوان معرّفة بـ CSS Variables مع انتقال ناعم بين الوضعين.

### 💾 تخزين محلي لمدة أسبوع

- كل البيانات تُحفظ في `localStorage` داخل متصفحك، **ولا تُرسل لأي سيرفر**.
- حفظ تلقائي عند أي تغيير.
- عند فتح التطبيق، تُحذف تلقائياً المهام التي مرّ على موعدها أكثر من 7 أيام.

## 🛠️ التقنيات المستخدمة

| التقنية | الاستخدام |
|---|---|
| **React 18.3.1** (UMD عبر CDN) | بناء الواجهة بـ Hooks (`useState`, `useEffect`, `useMemo`, `useCallback`) |
| **Babel Standalone 7.24** | تشغيل JSX مباشرة في المتصفح بدون Build |
| **HTML5** | هيكل الصفحة بوسوم دلالية وإتاحة (ARIA) |
| **CSS3** | Grid، Flexbox، `clamp()`، `backdrop-filter`، متغيرات CSS، أنيميشن |
| **JavaScript (ES6+)** | منطق التخزين، التواريخ، والـ Confetti |
| **Google Fonts (Cairo)** | الخط العربي |

> لا يوجد `npm` ولا `webpack` ولا أي خطوة بناء. الملف يعمل كما هو.

## 🗄️ البيانات المخزّنة

| المفتاح في `localStorage` | المحتوى |
|---|---|
| `tasks` | قائمة المهام (العنوان، الوصف، الأولوية، اليوم، الحالة) |
| `goals` | الأهداف الأسبوعية |
| `theme` | الوضع المختار (`light` أو `dark`) |
| `lastCleanup` | تاريخ آخر تنظيف للمهام القديمة |

شكل المهمة:

```json
{
  "id": "1737000000000",
  "title": "مراجعة الدرس",
  "desc": "الفصل الثالث",
  "pri": "high",
  "day": "2026-10-24",
  "status": "daily",
  "created": 1737000000000
}
```

القيم الممكنة لـ `status`: `daily` ، `doing` ، `done`.

## 🚀 التشغيل

### محلياً

1. حمّل الملف `index.html`.
2. افتحه بأي متصفح حديث بنقرتين.

> يحتاج اتصال إنترنت لتحميل React والخط من الـ CDN.

### على GitHub Pages

1. ارفع `index.html` إلى مستودع Public.
2. من **Settings ← Pages** اختر **Deploy from a branch**، والفرع **main**، والمجلد **/ (root)**.
3. افتح الرابط الذي يظهر بعد دقائق، وفي هذا المشروع: https://nawraswadi.github.io/weekly-planner/

## 🎨 تخصيص الألوان

كل الألوان في بداية قسم `<style>` داخل `index.html`:

```css
:root{
  --pr:#6366F1;   /* اللون الأساسي (بنفسجي) */
  --ac:#F59E0B;   /* لون التحفيز (برتقالي) */
  --ok:#10B981;   /* لون النجاح (أخضر) */
  --bg:#F8FAFC;   /* خلفية الوضع الفاتح */
}
:root[data-theme="dark"]{
  --bg:#0F172A;   /* خلفية الوضع الداكن */
  --solid:#1E293B;/* بطاقات الوضع الداكن */
}
```

غيّر القيم، احفظ، وحدّث الصفحة.

### إضافة عبارات تحفيزية

ابحث عن المصفوفة `QUOTES` في الكود وأضف عباراتك:

```js
const QUOTES=["الخطة بدون التزام مجرد أمنية.", "عبارتك هنا"];
```

## ♿ إمكانية الوصول والتجاوب

- اتجاه RTL كامل (`dir="rtl"` و`lang="ar"`).
- `aria-label` للأزرار والحقول، وتركيز واضح للوحة المفاتيح.
- تصميم متجاوب: الأقسام تتحول إلى عمود واحد على الموبايل.
- احترام إعداد تقليل الحركة (`prefers-reduced-motion`).
- دعم المناطق الآمنة (Safe Area) في الهواتف.
